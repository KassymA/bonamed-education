# BONAMED Education — Certificate Verification

Готовый минимальный сайт для Vercel.

## Быстрый запуск

1. Создайте новый репозиторий на GitHub, например `bonamed-cert`.
2. Загрузите все файлы из этой папки в репозиторий.
3. Откройте Vercel → Add New → Project.
4. Выберите репозиторий `bonamed-cert`.
5. Нажмите Deploy.
6. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://bonamed-cert.vercel.app`

## Где менять сертификаты

Откройте файл:

`data/certificates.ts`

Добавляйте новые записи по образцу:

```ts
{
  id: "BMD-2026-003",
  name: "Фамилия Имя Отчество",
  course: "Название курса",
  hours: "24 академических часа",
  date: "29 сентября 2026",
  organization: "ТОО «Бонамед»",
  status: "valid"
}
```

Статусы:
- `valid` — действителен
- `revoked` — аннулирован
- `expired` — срок действия завершён
